PSADT Wizard
PowerShell wizard that simplifies creation of PSAppDeployToolkit deployments.
Features
* Interactive deployment wizard
* Automatic Invoke-AppDeployToolkit.ps1 updates
* Detection rule recommendations
* Supports version-based detection
* Designed for Workspace ONE and other modern endpoint management platforms
Requirements
* PowerShell 7+
* PSAppDeployToolkit
