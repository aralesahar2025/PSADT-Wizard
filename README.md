# PSADT Wizard

A PowerShell-based interactive wizard that simplifies the creation and customization of PSAppDeployToolkit deployments.

PSADT Wizard guides administrators through common deployment configuration tasks and automatically updates the deployment script based on their selections, reducing the learning curve and helping accelerate package creation.

---

## Overview

PSAppDeployToolkit (PSADT) is one of the most popular frameworks for application deployment on Windows. While powerful and flexible, new administrators can find it intimidating to configure and customize.

PSADT Wizard was created to simplify the process by providing an interactive, question-driven experience that helps generate and update deployment configurations quickly and consistently.

The wizard reads and updates the PSADT deployment script based on administrator input while maintaining standard PSADT practices.

---

## Features

✅ Guided package creation workflow

✅ Interactive deployment configuration

✅ Automatic modification of `Invoke-AppDeployToolkit.ps1`

✅ Application metadata configuration

✅ Version-aware detection recommendations

✅ Simplified packaging experience for new administrators

✅ Consistent deployment configuration across packages

✅ Compatible with modern endpoint management platforms

- Omnissa Workspace ONE UEM
